# ST-Sidestory
실리태번의 현재 채팅으로 스토리·분석·내면·HTML·AU 프로필을 만드는 확장입니다. 다면은 인물 정보 추출 → 항목별 수정·승인 → 원본 없이 AU 생성의 2단계이며, 추출 화면에서 복사·PNG·텍스트/JSON 저장을 지원합니다.
확장 설치에서 이 저장소 URL을 입력한 뒤, 채팅방의 **요술봉 → Side Story**로 실행하세요.

## 요청이 전송되는 방식 (0.10.0)
**현재 실리태번 연결**에서는 RP 프리셋(캐릭터·페르소나·월드인포·채팅 히스토리·문체 지침)을 그대로 쓰고, Side Story 요청을 `<SIDESTORY>…</SIDESTORY>` 블록으로 묶어 **마지막 유저 메시지**로 붙입니다. 프리셋의 시스템 메시지 합치기(squash)가 켜져 있어도 이 블록은 따로 분리돼 맨 끝에 놓입니다. 결과 화면의 **프롬프트 내역 → 최종 전송 프롬프트**에서 실제로 보낸 전체 메시지를 확인할 수 있습니다.

- **RP 프리셋 적용 범위**(설정 → 프롬프트): 프리셋에서 그대로 따를 것(문체·포맷·금지어 등)과 이번 요청에서만 내려놓을 것(다음 턴 진행, 응답 길이, 상태창 등)을 적는 안내입니다. 프리셋에 맞게 고칠 수 있습니다.
- **시점**(스토리·쓰기·HTML): 자동 / 본편 이후 / 과거·회상 / 독립·AU.
- **본편 대화 개수**(참고 설정): 숫자를 직접 입력합니다. 비우면 전체(ST 컨텍스트 한도 안), 0이면 본편 대화를 넣지 않습니다. ST 경로에서도 `generate_interceptor`로 적용됩니다.
- **이어쓰기**: 이전 편들은 **채팅 히스토리 안에** 들어갑니다. 본편 대화(시리즈 첫 편을 만든 시점까지) 뒤에 `OOC: Side Story request (part n) — 요청` 유저 메시지와 그 편 본문(캐릭터 메시지)이 차례로 붙고, 마지막 유저 메시지에는 짧은 이어쓰기 요청과 재개 지점(`<resume_point>`)만 들어갑니다. 이어쓰기 패널에서 본편 대화를 빼면 히스토리는 시리즈 편들만으로 구성됩니다. 이전 편이 길면 오래된 편은 숨김 요약(recap)으로 대신합니다.
- **다시 만들기**는 결과가 만들어진 방식(새로 쓰기·이어쓰기·수정)을 같은 이전 편으로 다시 실행합니다.
- 스토리·쓰기 결과는 끝에 숨김 `<recap>` 요약을 함께 받아 두었다가, 시리즈가 길어지면 앞선 편 대신 사용합니다.

별도 요약 확장(내장 Summarize, Qvink, Memory Books 등)은 ST가 프롬프트를 조립할 때 함께 들어갑니다. 확장 설정에 "백그라운드/quiet 생성에는 주입하지 않음" 같은 옵션이 있다면 꺼 두세요.

## 추론 블록 제거 (0.12.0)
설정 → **정규식 · 추론**에서 결과에서 지울 추론 블록을 관리합니다. 기본으로 `<thinking>`과 `<think>`가 들어 있고, 이 둘은 끌 수만 있고 삭제할 수는 없습니다. 블록 이름(예: `cot`)만 입력하면 `<cot>…</cot>`도 지웁니다.
- 결과를 저장하기 전에 지우므로 저장본·recap·이어쓰기·번역 어디에도 남지 않습니다.
- 프리셋이 여는 태그를 프리필해서 응답이 `…</thinking>`으로 시작하는 경우, 닫는 태그까지를 지웁니다.
- 닫히지 않은 블록은 그 지점부터 끝까지 지웁니다. 지운 뒤 남는 내용이 없으면 원문을 그대로 둡니다.

## 화면 구성 (0.13.0)
휴대폰 기준으로 다시 짠 화면입니다. 폭 900px 이상에서는 작성 | 결과 두 칸으로 나뉘고 위쪽 막대에 보관함 · 내역 · 설정이 붙습니다.
- **휴대폰**: 하단 탭(작성 · 결과 · 보관함 · 내역 · 설정). 결과 화면은 위쪽 막대 대신 `‹ 제목 ☆ ✕`만 두고, 본문이 화면 전체를 쓰며 한 번에 스크롤됩니다.
- **시리즈**: 제목 아래 `1편 2편 3편 …` 한 줄(넓은 데스크톱에서는 본문 왼쪽 여백). `목록`/`전체 N`으로 분기까지 모든 편을 봅니다.
- **결과 하단**: 이어쓰기 · 다시 쓰기 · 더보기. 다시 쓰기는 *고쳐 쓰기*(지금 결과를 두고 적은 점만 수정)와 *새로 쓰기*(같은 요청으로 처음부터)를 고를 수 있고, 비워 두면 새로 씁니다.
- **시트**: 더보기·이어쓰기·다시 쓰기·참고 자료·폴더/태그·각종 확인 창은 아래에서 올라오는 시트(데스크톱은 가운데 창)로 열립니다.
- **보관함**: 목록형. 시리즈는 한 줄로 묶이고, 각 줄의 `⋯`에서 폴더·태그·삭제를 합니다.
- **다크 모드**: 본문 배경도 테마를 따릅니다.

## RP 프리셋 선택
참고 자료 → 대화 · 요약의 **RP 프리셋**에서 Side Story 생성에 쓸 프리셋을 고릅니다. 생성하는 동안만 그 프리셋으로 바꾸고, 끝나거나 실패·중단되면 원래 프리셋으로 되돌립니다. 바뀌어 있는 동안 본편 전송 버튼은 막힙니다. 현재 실리태번 연결에서만 적용됩니다. 프리셋에 API·모델 연결이 묶여 있으면 그것도 함께 바뀌었다 돌아옵니다.


### 0.15.13 — 형식별 보조 대화

설정 → 형식별 프리셋에서 사용자 프리셋을 선택하거나 내장 프리셋을 복제하세요. ‘보조 대화’를 켜고 ASSISTANT와 USER 내용을 입력한 뒤 저장하면, 생성 요청 끝에 두 메시지가 순서대로 추가됩니다. ASSISTANT 내용은 사용자가 작성한 예시 응답이며 추가 API 호출은 없습니다. 기본값은 OFF이고, 끄더라도 내용은 보존됩니다. 두 입력칸이 모두 있어야 활성 상태로 저장할 수 있습니다.

새 생성·이어쓰기·수정·재생성은 해당 형식에 현재 선택된 프리셋의 저장된 내용을 사용합니다. 번역·다면 인물 추출 및 AU 생성에는 적용하지 않습니다. 프리셋 백업·복원과 복제에 포함되며 실제 RP 채팅에는 기록하지 않습니다. 전송 내용은 프롬프트 내역에서 확인할 수 있습니다. 실리태번 본편 연결에서는 CHAT_COMPLETION_PROMPT_READY 이벤트를 지원하는 채팅 완성 API가 필요하며, 지원하지 않는 경로는 안내 후 전송을 중단합니다. 모델의 응답이나 요청 수락을 보장하는 기능은 아닙니다.

### 0.16.0 — 읽기 도구 · 테마 색

- **설정 구역 제목**: 생성 · 프롬프트 · 읽기·화면 · 데이터 제목을 테마 색의 굵은 글씨로 키워 구역이 잘 나뉘어 보여요.
- **더보기 구역 구분**: 편 더보기 시트의 묶음 경계선을 2px 굵기의 테마 색으로 바꿔 구역이 잘 보여요.
- **테마 색**(설정 → 읽기·화면): 버건디 · 진녹색 · 진한 파랑 · 보라 · 적갈색 · 차콜 중에서 고르거나 무지개 원을 눌러 직접 고를 수 있어요. 밝게/어둡게 테마에 맞춰 강조색이 자동으로 조정돼요.
- **편 이동 버튼**(설정 → 읽기·화면, 기본 꺼짐): 결과 화면 왼쪽이나 오른쪽에 *이 편 맨 위 · 이전 편 · 다음 편 · 이 편 맨 아래* 버튼을 띄워요. 이전·다음은 지금 읽는 갈래 안에서만 움직여요.
- **이어쓰기 옵션**: 이어쓰기 방식 시트에서 형식이 말하기면 *묻는 사람 · 말하는 방식 · 속마음 함께 보기*를, 쓰기면 *쓰는 방식*을 고를 수 있어요. 처음 값은 지금 보고 있는 편을 만들 때 쓴 값이고, 여기서 바꾼 값은 이번 이어쓰기에만 적용되며 새로 쓰기 화면 설정은 그대로 둬요.
- **새 채팅 범위**: 시리즈의 2편 이후에서 *이 결과로 새 채팅 시작*을 누르면 *이 편만* 또는 *1편부터 이 편까지*를 고를 수 있어요. 후자는 지금 갈래의 각 편 원문을 캐릭터 메시지 하나씩 순서대로 넣어요(다른 갈래와 번역·요청은 넣지 않아요).

### 0.16.1 — 시리즈 전체 보기 정리

- 편마다 같은 높이의 한 줄로 정리했어요. 왼쪽 번호가 몇 편인지 보여 주고(갈래는 같은 번호), 아래 줄에는 형식 · 시작/이어짐/갈래 · 미완료만 표시해요.
- 계단식 들여쓰기와 글자가 위아래로 잘리던 문제를 고쳤고, 지금 보는 편은 줄 전체가 강조돼요.
